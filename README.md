# Torqway — mobile mechanic website (concept by Orbient)

**Live:** https://orbient.github.io/torqway/

A concept website for a mobile auto repair service in the Phoenix metro, AZ.
The shop, phone, prices and reviews are fictional; the site shows what [Orbient](https://orbient.pro/en) builds for real businesses.

What's inside: instant flat-rate quote calculator with a ZIP check, 4-step booking with a live price, a repair text thread that plays out (ETA → photo → quote → approve), service-area map with vans on their routes, live open/closed status in Phoenix time, prerendered HTML and zero layout shift.

This branch holds the built site only.
